# Order Management System

## Description

This mini app is designed to calculate order total price and provide information about order status. It calculates total order price based on product price and quantity. It also calculates the delivery fee and final payment. The app rejects the invalid input if a customer entered an incorrect data type (or entered 0)

## Features

- Calculates the order totat based on price and quantity, and returning Invalid input if we received an incorrect data
- Calculates the delivery fee based on the order total.
- Checking order status
- The app displays an error message when the input is invalid.

## Technologies

- JavaScript
- Node.js

## How to Run

1. Open a terminal.
2. Navigate to the mini-project-01 directory.
3. Run the application using Node.js:
   `node app.js`
