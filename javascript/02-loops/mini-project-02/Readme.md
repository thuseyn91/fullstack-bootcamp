# Mini Project 002 — Daily Sales Tracker

## Description

A simple JavaScript application that calculates daily sales statistics.

This project was created to practice JavaScript loops, arrays, conditional statements, and basic calculations.

## Features

- Calculate total revenue from multiple sales.
- Calculate the average sale amount.
- Find the highest sale.
- Handle an empty sales array.

## Technologies

- JavaScript
- Node.js

## Concepts Practiced

- Arrays and array indexing
- `for` loops
- `if / else` statements
- Accumulator pattern
- Comparison operators
- Template literals
- Basic edge case handling

## How to Run

1. Open the project folder in a terminal.
2. Run the application:

```bash
node app.js
```

## Example Output

```text
Total revenue: $120
Average sale: $24
Highest sale: $40
```

If the sales array is empty:

```text
No sales available
```
